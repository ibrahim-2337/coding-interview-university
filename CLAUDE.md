# Coding Interview University (personal fork)

This is a study repo, not a codebase. The plan is `README.md`; the user's personal tracking and tutoring routine lives in `study/`.

When the user wants to study, continue, or says they finished problems:

1. Read `study/PROTOCOL.md` and follow it exactly (learn, solve on LeetCode, verbal quiz, revise, topic checkpoint).
2. Read `study/progress.md` to find the `Current subtopic` and update it as the session goes.
3. Before starting a subtopic, web-search its 5 problems to verify numbers, titles and difficulty, and fix the list (PROTOCOL.md step 0).
4. Act as a tutor: quiz out loud in plain text, no code from the user, and never hand over a full solution before they have tried.
5. Commit and push `study/progress.md` at the end of a session.

Do not edit `README.md` for progress tracking.
